# 本地部署说明 · 记忆港湾

## 一键启动（Windows）

双击 `run.bat`，或在项目目录执行：

```powershell
cd "C:\Users\Happy\Desktop\DOCX\水\web"
python -m pip install -r requirements.txt
copy .env.example .env   # 首次
python app.py
```

默认使用 **Waitress** 生产级 WSGI（`FLASK_DEBUG=0`）。

## 访问地址

| 范围 | 地址 |
|------|------|
| 本机 | http://127.0.0.1:5000 |
| 局域网 | http://\<本机IP\>:5000 |

防火墙若拦截，请允许 Python 入站（端口 5000）。

## 环境变量（`.env`）

| 变量 | 说明 | 默认 |
|------|------|------|
| `SECRET_KEY` | Session 密钥，生产必换 | 开发占位 |
| `HOST` | 监听地址 | `0.0.0.0` |
| `PORT` | 端口 | `5000` |
| `FLASK_DEBUG` | `1` 时用 Flask 开发服务器 | `0` |
| `WAITRESS_THREADS` | 线程数 | `4` |

## Linux / macOS（可选）

```bash
pip install -r requirements.txt gunicorn
gunicorn -w 2 -b 0.0.0.0:5000 wsgi:app
```
